# 拆解器

> **帮你看清问题本身** —— ★ **它不替你下结论。**

你卡住了。而「卡住」那一刻最难的不是找答案，是**说不清自己卡在哪一句**。

把那一句原样打进来。它不给你建议，它给你三样东西：**你真正卡在哪一句 · 这个问题有几面 · 有哪几条路**。
然后它把结论**还给**你。

---

## 从零跑起来（三步）

### 1 · 装依赖

需要 **Python 3.10+**（Linux/macOS/Windows 都行）。

```bash
pip install fastapi uvicorn pydantic httpx
```

> ★ 只有这四个。**不装 torch、不下载模型、不联网初始化。**

### 2 · 填你自己的 API Key

```bash
cp _env.example .env.local
```

打开 `.env.local`，把这一行填上你自己的 DeepSeek Key：

```
DEEPSEEK_API_KEY=sk-你的key
```

> ★ 这个文件**不会**进仓库（`.gitignore` 挡着）。
> ★ 拿 Key：<https://platform.deepseek.com/api_keys>

### 3 · 起服务

```bash
python app/server.py
```

看到 `http://127.0.0.1:8394` 就打开它。

**★ Windows 桌面窗口**：双击 `启动拆解器.bat` —— 它会弹一个**没有地址栏、没有标签页**的独立窗口（像一个普通桌面软件）。想放到桌面：双击一次 `创建桌面快捷方式.py`。
**★ 停止**：`关闭.bat`（或 `Ctrl+C`）。

## 它是什么 / 不是什么

| | 它**是** | 它**不是** |
|---|---|---|
| 姿态 | 帮你看清：你卡在哪一句、这问题有几面、有哪几条路 | ★ **不给你答案，不说「你应该」** |
| 判据 | 用方向锥 + 组合判据把偏移**显形** | ★ **不修正你的智能体、不自动触发动作** |
| 数据 | 全在你本机（`127.0.0.1`），对话存 `data/` 与 `history/` | ★ **不上传任何东西到作者的机器** |

---

## 安全边界（★ 请照实掂量）

**`127.0.0.1` 挡得住别的机器，挡不住同一台电脑上的其它程序。** 故本工具按「**单人使用的电脑**」设计：别在多人共用、或来路不明的软件乱装的机器上填入你的 Key。

**Key 只出网到一个地方**：`https://api.deepseek.com`（`base_url` 已锁白名单，改不了）。故没人能借这个服务把你的 Key 发去别处。

**界面能设 Key，而别的网页设不了**：保存请求必须带一个**本机令牌**（服务启动时随机生成、只注入本服务打开的页面）。没有它 ⇒ `403`。

## 可选：接更完整的判据账

本工具的**核心不依赖任何外部件**。它可选地读三样更完整的判据账：

| 模块 | 作用 | 缺了会怎样 |
|---|---|---|
| `check_criteria` | 判据表的**结构指纹** | 记 `null`，不报错 |
| `criterion_status` | 判据落实状况一行读数 | 明说「缺件」 |
| `direction_history` | 两本账的对账 | 记 `"ok": false, "why": "未接：…"` |

**★ 三个都是 `try/except` 包着的** —— 缺了它**照样跑**，只是少了那三项读数，且会**明说「未接」**（★ 不静默跳过）。要接它们，把它们放进 `checks/` 下。
